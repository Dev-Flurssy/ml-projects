ML is teaching a computer by giving it example instead of giving it step by step instruction, or learning patterns from data

Supervised is a type of ml model that learns from labelled data where each input has an output, it compares its prediction with actual result learn from it and improve over time it adjusts itself to reduces prediction error. It is used whenever we want to get a specific output from a given input goal is to make accurate prediction for new data. it is divided into classification and regression.


Classification teaches the computer how to put things into groups by learning from labelled examples to predict new labels for new data showing it example of things with groups and labels it then assigns new data into groups with labels or assign it its own labels.
It predicts labels or categories from input data, it assigns a data point to a specific class or label based on learned patterns type of classification depends on how many classes exist and how categories are structured. divided into binary and multi classification

Binary classification data is divided into two possible categories, it analyzes the features and based on pattern decide which category input belongs to
Binary cross Entropy is a loss function used in binary classification, it quantifies the difference between the actual class labels and the predicted the lower the binary entropy value the higher the the prediction accuracy 

Multiclass is when a data is assigned to one class from more than two categories of class eg Decision Tree, Support Vector Machine(SVM), KNN, Native Bayes eg digit recognition, species identification, and product categorization.

Multilabel classification is when a single data instance can belong to various classes simultaenously rather than being restricted to one class
xteristics: 
Categories are not mutually exclusive 
Output is a set of label instead one one 
Each label is represented as preset or absent
eg A review online 

Classification Working 
Data Collection: each data has a correct label 
Feature extraction: identify features that can help distinguish classes 
Model training: pick a model and train based on data
Model evaluation: model is tested with new data to test accuracy  
Model prediction: predicts new unseen data aka model improvement

Classification Algorithms 

linear Classifiers creates a linear boundary(straight line plane, hyperplane ) between classes depending on dimensions eg Logisitic Regression, Support Vector Machine(SVM), Single Layer Perceptron, Stochastic Gradent Descent (SGD) Classifier.

Non Linear Classifiers creates non linear decision(curve or flexible boundaries ) thin stad of lines and planes capturing more complex relationship between input features and target variable eg KNN, Kernel SVM, Decision Tree, Random Forest, Native Bayes, Ada Boost, Voting Classifier, Bagging Classifier, Extra Trees Classifier, and Multi layer Artificial Neural Networks.



Regression is a supervised learning technique used to predict continous numerical value learning relationship between an input feature and output variable.
It helps to understand how changes in one factor affects the outcome. It is used in forecasting risk, analysis, decision making, and trend estimation.
It teaches the computer to predict a number by learning from examples and predicting a continous value predicting the price of a house or annual salary of an employee by feeding it type, size, amount per rooms etc.

Regression type is based on predictor variables and nature of relationship
Simple Linear Regression models the relationship (by drawing a straight line (minimizing the mean square error) that best fits between an independent(input) and a continous dependent (output) variable. It is simple and interpretable but can't capture complex relationship due to it simplicity 
eg predicting score of student based on hours studied
Gradient Descent is an optimization algorithm used to minimize error of machine learning model by updating parameters in direction of decreasing loss

Types of Linear Regression 
Univariate is one which the output depends on only one independent input value
Multivariate when we need to predict more than one output at the same time 

Note: Simple linear Regression is same as univariate

Multiple Linear Regression involves more than one independent variable and dependent variable to be provided 
Polynomial regression is a linear regression with curved lines 

ridge and lasso are regularised linear regression that adds penalty terms to limit large coefficient and overfitting 
Ridge is a version of LR that adds an l2 penalty to control large coefficents, minimizing error but becomes unstable when feature are highly correlated
Lasso is a LR technique that imporoves model generalization by using l1 regularization by adding penalty which controls overfitting, and performs automatic feature selection by reducing coefficents to zero.

Support Vector Regression SVR predict continous value by fitting a function within a defined error margin using kernel function to handle linear and complex
Decision Tree is used to predict continous values such as prices or scores using a tree like structure
Random forest combines multiple decison trees to produce more accurate and stable prediction

Understanding Generalization, Overfitting, Underfitting, and Model Complexity

Generalization means the model performs well on new data not just the data it was trained with, it has learned and understand related paterns in data provided therefore can answer questions related to the data or new data provided

Overfitting means it memorized the data provided but doesn't understand it so when new data is provided it can't answer questions related to it building a model that is too complex for the data we have is called overfitting because it works well with train set but doesn't on new data

Underfitting means the model is too simple and fails to learn the real pattern that is it looks at one aspect of the trained data and doesn't learn or understand other aspect of the data therefore can't make predictions on new data performing poorly

Note: the more complex our model the better the prediction but we shouldn't make it overly complex.

Model complexity is how smart or flexible the model is, dataset size is the amount or examples of data fed to the model to learn from the more complex your model the more data is needed the more simple the less data is needed.
- when model is complex and data is small it memorizes and overfit instead of understanding and generalizing 
- when data is large and model is simple it underfits it cant capture all the pattern in the rich data 

High dimensional datasets have many features while low dimensionl have few features.
