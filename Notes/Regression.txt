REGRESSION

Regression is a supervised learning technique used to predict continuous numerical values. It learns the relationship between input features and an output variable. It helps us understand how changes in one factor affect the outcome. Regression is used in forecasting, risk analysis, decision making, and trend estimation.

It teaches the computer to predict a number by learning from examples and producing a continuous value.  
Example: predicting the price of a house or annual salary of an employee using features like size, type, number of rooms, etc.

Regression is based on predictor variables and the nature of their relationship with the output.

------------------------------------------------------------
SIMPLE LINEAR REGRESSION

Simple Linear Regression is a statistical technique used to models the relationship between one independent variable (input) and one continuous dependent variable (output). It draws a straight line that best fits the data by minimizing the mean squared error. 

It is simple and interpretable but cannot capture complex relationships because it only fits a straight line.  
Example: predicting a student’s score based on hours studied.

------------------------------------------------------------
 
 TYPES OF LINEAR REGRESSION

Univariate Linear Regression  
Output depends on only one independent input variable. (Same as simple linear regression.)

Multivariate Regression  
Predicts more than one output at the same time.

Multiple Linear Regression  
Uses more than one independent variable to predict a single dependent variable.

Polynomial Regression  
A form of linear regression that fits curved lines by adding polynomial terms.

------------------------------------------------------------
REGULARIZED LINEAR REGRESSION

Ridge Regression  
Adds an L2 penalty to limit large coefficients and reduce overfitting. It minimizes error but can become unstable when features are highly correlated.

Lasso Regression  
Adds an L1 penalty to improve generalization and control overfitting. Lasso can reduce some coefficients to zero, performing automatic feature selection.

Regularization Strength (λ)  
λ controls how strong the penalty is.  
Large λ → simpler model  
Small λ → more flexible model

------------------------------------------------------------
OTHER REGRESSION MODELS

Support Vector Regression (SVR)  
Predicts continuous values by fitting a function within a defined error margin. Uses kernel functions to handle both linear and complex relationships.

Decision Tree Regression  
Predicts continuous values using a tree‑like structure that splits data based on feature conditions.

Random Forest Regression  
Combines multiple decision trees to produce more accurate and stable predictions.

------------------------------------------------------------
ASSUMPTIONS OF LINEAR REGRESSION

Linear regression works best when these assumptions hold:
- Linearity: relationship between input and output is linear  
- Independence: observations are independent  
- Homoscedasticity: constant variance of errors  
- Normality: errors are normally distributed  
- No multicollinearity: features should not be highly correlated  

These assumptions explain why linear regression sometimes fails.

------------------------------------------------------------
LOSS IN MACHINE LEARNING  

Loss is a number that shows how far off a model’s predictions are from the actual values. You can think of it as arrows drawn from each data point to the model’s prediction, the longer the arrow, the bigger the mistake. Training a model means adjusting it so those arrows get shorter, reducing the loss.  

Short arrows → the prediction is close to the truth → small loss.
Long arrows → the prediction is far from the truth → large loss.

The training process is all about adjusting the line so those arrows get shorter and shorter, meaning the model is learning to make better predictions.


Common loss functions in regression:  
- L1 Loss: Sum of absolute errors  
- MAE (Mean Absolute Error): Average of absolute errors  
- L2 Loss: Sum of squared errors  
- MSE (Mean Squared Error): Average of squared errors  
- RMSE (Root Mean Squared Error): Square root of MSE  

------------------------------------------------------------
DISTANCE OF LOSS  

Loss measures the difference between predicted and actual values. It focuses on the distance, not the direction. For example, if the model predicts 2 but the actual value is 5, the difference is –3. We don’t care about the negative sign, only that the distance is 3.  

To remove the sign, loss functions use:  
- Absolute value → |actual − predicted|  
- Square of the difference → (actual − predicted)²  

------------------------------------------------------------  
CHOOSING A LOSS FUNCTION  

The choice of loss function affects how the model handles outliers (values far from the typical range).  

MSE (Mean Squared Error):  
- Squares errors, so large mistakes count much more  
- Model shifts closer to outliers, further from normal points  
- Good if outliers are important and represent true data  
- Often easier to optimize mathematically  
- RMSE brings error back into the same units as labels  

MAE (Mean Absolute Error):  
- Treats all errors equally by taking absolute values  
- Model stays closer to most points, less influenced by outliers  
- More robust when you don’t want outliers to dominate  
- Directly interpretable as the average error size  

Quick rule of thumb:  
- MSE if big errors matter a lot. If you believe the outliers are important and indicative of true data variance that the model should account for.
- MAE if you want stability and less sensitivity to unusual data, i.e your dataset has significant outliers that you don't want to overly influence the
  model. 

------------------------------------------------------------
GRADIENT DESCENT  

Gradient descent is a mathematical technique that helps a model find the best weight and bias (the line’s slope and intercept) that minimize loss. 
It works by starting with random values and then improving them step by step.  

Process:  
1. Start with random weights and bias near zero.  
2. Calculate the loss with the current values.  
3. Figure out the direction to adjust the weights and bias to reduce loss.  
4. Move them a small step in that direction.  
5. Repeat until the model can’t reduce the loss any further.  


It does not measure error. It reduces error.

Think of it like this:
Loss function = tells you how wrong the model is
Gradient descent = tells you how to fix it

It is like walking downhill in fog, you can’t see the bottom, but at each step you feel which way is downhill and move a little in that direction. 
Eventually, you reach the lowest point, the minimum loss.  

------------------------------------------------------------  
MODEL CONVERGENCE 

For a model to converge means that during training, it has reached the point where further updates to the weights and bias no longer reduce the loss in a meaningful way. In other words, the model has “settled” into its best possible fit for the data given the chosen loss function and training process.

------------------------------------------------------------
LOSS CURVES  

When training a model, you often look at a loss curve to check if the model has converged. The loss curve plots loss (y‑axis) against iterations (x‑axis).  

- At the start, loss is high because the weights and bias are random.  
- As training continues, loss decreases as the model learns better weights and bias.  
- Eventually, the curve flattens, this means the model has converged, or reached the point where further training doesn’t reduce loss significantly.  

A smooth downward curve that levels off shows successful convergence. 
If the curve stays high or fluctuates without settling, the model hasn’t converged properly.  

------------------------------------------------------------
CONVERGENCE AND CONVEX FUNCTIONS  

For linear models, the loss surface is always convex, shaped like a smooth bowl with one lowest point. 
This property guarantees that when the model converges, it has found the weights and bias that give the minimum possible loss.  

If we graph the loss surface for one feature:  
  - X‑axis = weight  
  - Y‑axis = bias  
  - Z‑axis = loss  
  - The surface looks like a convex bowl.  

- Gradient descent moves the weights and bias step by step downhill on this surface.  
- The path looks like a ball rolling down the bowl until it reaches the bottom.  
- At the bottom, there’s no more downward slope, this is the minimum loss, and the point of convergence.  

------------------------------------------------------------  
PARAMETERS VS HYPERPARAMETERS AND LEARNING RATE  

Parameters are the values inside the model itself, like the weights and bias, which the model calculates and updates during training. 
Hyperparameters are values you set before training that control how the model learns, such as the learning rate.  

LEARNING RATE  
- The learning rate is a hyperparameter in gradient descent.  
- It controls how big or small the steps are when updating the model’s parameters.  
- It decides how quickly or slowly the algorithm moves toward the minimum of the cost function.  

How it works:  
- Gradient descent calculates the slope of the loss function.  
- The slope is multiplied by the learning rate to decide how much to change the parameters.  
- Example: if the slope is 2.5 and the learning rate is 0.01, the parameter changes by 0.025.  

The ideal learning rate helps the model reduce loss quickly in the first few iterations, then gradually flatten out as it converges.  

------------------------------------------------------------  
EFFECTS  

1. Too Small  
- Tiny steps → very slow convergence.  
- Training takes a long time, especially with large datasets.  

2. Too Large  
- Huge steps → overshoot the minimum.  
- Model may fail to converge and oscillate back and forth (exploding gradient problem).  

------------------------------------------------------------  
TECHNIQUES TO HANDLE LEARNING RATE ISSUES  

- Weight Initialization: Start with properly scaled weights.  
- Gradient Clipping: Restrict gradients to a fixed range.  
- Batch Normalization: Normalize inputs at each layer to stabilize training.  
- Activation Functions: Use ReLU instead of sigmoid/tanh to reduce vanishing gradients.  

------------------------------------------------------------  
KEY IDEA  

Choosing the right learning rate = fast and stable convergence.  
- Small → safe but slow.  
- Large → risky but fast.  
- Often tuned experimentally or adjusted dynamically during training.  

------------------------------------------------------------  
BATCH SIZE

Batch size is a hyperparameter that controls how many examples the model processes before updating its weights and bias.
Using the entire dataset at once (full batch) is often impractical for very large datasets, so smaller batches are used.

Two common approaches:
- Stochastic Gradient Descent (SGD)
- Mini‑Batch Stochastic Gradient Descent

------------------------------------------------------------  
STOCHASTIC GRADIENT DESCENT  

Stochastic Gradient Descent (SGD) is an optimization algorithm widely used in machine learning, especially for large datasets. 
It is a variant of gradient descent designed for faster and scalable learning.  

- Updates parameters using one data point or small batches at a time  
- Reduces computation compared to full batch gradient descent  
- Efficient for very large datasets and online learning  
- Widely used in deep learning for training models  

------------------------------------------------------------  
WORKING OF STOCHASTIC GRADIENT DESCENT  

In traditional gradient descent, gradients are computed using the entire dataset, which is computationally expensive.  
In SGD, the gradient is calculated for each training example (or a small subset) instead of the whole dataset. 
This makes updates faster but introduces more noise in the path of optimization.  

------------------------------------------------------------  
PATH COMPARISON  

- Batch Gradient Descent → smooth path toward minimum (uses all data each step)  
- Stochastic Gradient Descent → noisy zig‑zag path, but faster and scalable  

------------------------------------------------------------  
IMPLEMENTING STOCHASTIC GRADIENT DESCENT FROM SCRATCH  

- Generating the Data  
- Defining the SGD Function  
   - Initializes parameters randomly  
   - Adds a bias term to X  
   - Shuffles data each epoch  
   - Updates parameters using single samples or mini‑batches  
   - Tracks loss using Mean Squared Error (MSE)  

------------------------------------------------------------  
APPLICATIONS  

- Deep learning: training large neural networks  
- NLP: Word2Vec, transformers  
- Computer vision: image classification, object detection  
- Reinforcement learning: deep Q‑networks, policy gradient methods  

------------------------------------------------------------  
ADVANTAGES  

- Faster and efficient updates using few samples  
- Requires less memory, suitable for large datasets  
- Stochastic updates help escape local minima  
- Supports online learning  

------------------------------------------------------------  
CHALLENGES  

- Updates are noisy, causing fluctuations in loss  
- Sensitive to learning rate (too high → divergence, too low → slow learning)  
- May take longer to converge overall despite faster updates  

------------------------------------------------------------  
MINI‑BATCH STOCHASTIC GRADIENT DESCENT  

Mini‑Batch SGD is a compromise between full‑batch and pure SGD. 
Instead of using one example or the entire dataset, it processes a small group of examples per update.  

- Batch size can range from 2 to a few hundred, depending on dataset size and compute resources.  
- Each batch is chosen randomly, gradients are averaged, and weights/bias are updated once per iteration.  
- Small batch sizes behave more like SGD (noisy but fast).  
- Larger batch sizes behave more like full‑batch gradient descent (smoother but slower).  
- Mini‑batch training often achieves the best balance:  
  - Faster than full‑batch  
  - Less noisy than pure SGD  
  - Efficient use of hardware like GPUs (parallel processing works best with batches).  
- Widely used in practice because it combines efficiency, stability, and scalability.  

------------------------------------------------------------  
EPOCHS  

During training, an epoch means the model has processed every example in the training set once. 
For example, if the dataset has 1,000 examples and the mini‑batch size is 100, it takes 10 iterations to complete one epoch.  

Training usually requires many epochs, meaning the system processes the entire dataset multiple times. 
The number of epochs is a hyperparameter you set before training begins. 
Often, you need to experiment to find how many epochs are enough for the model to converge. 
More epochs generally improve the model but also increase training time.  

Relation between batch size and epochs:  

- Full batch: Updates weights and bias once per epoch.  
  Example: 1,000 examples, 20 epochs → 20 updates.  

- Stochastic Gradient Descent (SGD): Updates after each example.  
  Example: 1,000 examples, 20 epochs → 20,000 updates.  

- Mini‑Batch SGD: Updates after each batch.  
  Example: 1,000 examples, batch size 100, 20 epochs → 200 updates.

LOGISTIC REGRESSION  

Logistic Regression is a supervised machine learning algorithm used for classification problems. 
Unlike linear regression, which predicts continuous values, logistic regression predicts the probability that an input belongs to a specific class. 

- Used for binary classification where the output can be one of two categories such as Yes/No, True/False, or 0/1  
- Uses the sigmoid function to convert inputs into a probability value between 0 and 1  

------------------------------------------------------------  
TYPES OF LOGISTIC REGRESSION  

- Binomial Logistic Regression: Dependent variable has two categories (Yes/No, Pass/Fail, 0/1). Most common type. 
- Multinomial Logistic Regression: Dependent variable has three or more unordered categories (e.g., cat, dog, sheep).  
- Ordinal Logistic Regression: Dependent variable has ordered categories (e.g., Low, Medium, High).   

------------------------------------------------------------  
ASSUMPTIONS  

- Independent Observations: Each data point should be independent. 
- Binary Dependent Variable: Target variable is typically binary (0/1, Yes/No). Extensions like Softmax handle multiclass.  
- Linearity of Log-Odds: Independent variables should have a linear relationship with the log-odds.   
- No Extreme Outliers: Outliers can distort coefficient estimates.   
- Large Sample Size: A large dataset improves reliability.   

------------------------------------------------------------  
SIGMOID FUNCTION  

- Is a key component that converts raw model output into a probability between 0 and 1.    
- takes any real value mapping it into a range of 0 and 1 Producing an “S”-shaped curve. 
- Threshold (usually 0.5) determines class assignment. 

------------------------------------------------------------  
 WORKING OF LOGISTIC REGRESSION  

1. Linear combination of inputs  
- The model takes input features (like study hours, age, income).  
- Each feature is multiplied by a weight, then added together with a bias.  
- This gives a single number: z = w·X + b  

2. Sigmoid function  
- Logistic regression passes z into the sigmoid function:  
  σ(z) = 1 / (1 + e^(-z))  
- This converts any number into a probability between 0 and 1.  

3. Probability to class  
- If the probability is close to 1 → predict Class 2 (label = 1)  
- If the probability is close to 0 → predict Class 1 (label = 0)  
- A threshold of 0.5 is usually used:  
  - Probability ≥ 0.5 → Class 1  
  - Probability < 0.5 → Class 0  

------------------------------------------------------------  
EXAMPLE  

Predict if a student passes (1) or fails (0) based on study hours.  

- Input: x = 5 hours studied  
- Weight: w = 0.8, Bias: b = -2  
- Step 1: z = (0.8 × 5) + (-2) = 2  
- Step 2: σ(2) = 1 / (1 + e^(-2)) ≈ 0.88  
- Step 3: Probability = 0.88 → predict Pass (1)  

------------------------------------------------------------  
SIGMOID FUNCTION IN BACKPROPAGATION  

- A linear activation can only separate data linearly → poor on non‑linear datasets.  
- Adding a hidden layer with sigmoid activation lets the model handle non‑linearity → better performance.  

During backpropagation, the model updates weights and biases using the derivative of the activation function. The sigmoid is useful because:  
- It is differentiable everywhere.  
- Its derivative has a simple form that involves itself.  

------------------------------------------------------------  
DERIVATIVE OF SIGMOID FUNCTION  

Sigmoid function:  
σ(x) = 1 / (1 + e^(-x))  

Derivative:  
σ′(x) = σ(x) · (1 − σ(x))  

This neat property makes gradient calculations efficient.  

------------------------------------------------------------  
ISSUE WITH SIGMOID FUNCTION  

- When x is very large or very small, σ′(x) becomes close to 0.  
- This causes the vanishing gradient problem: updates to weights and biases become tiny.  
- As a result, the model learns very slowly or may stop learning in deep networks.  

------------------------------------------------------------  
PROBLEM 1: Derivative at x = 0  

Step 1: Compute sigmoid at 0  
σ(0) = 1 / (1 + e^0) = 1 / 2 = 0.5  

Step 2: Apply derivative formula  
σ′(0) = σ(0) × (1 − σ(0))  
= 0.5 × (1 − 0.5)  
= 0.25  

Answer: σ′(0) = 0.25  

------------------------------------------------------------  
PROBLEM 2: Derivative at x = 2  

Step 1: Compute sigmoid at 2  
σ(2) = 1 / (1 + e^(−2)) ≈ 0.88  

Step 2: Apply derivative formula  
σ′(2) = 0.88 × (1 − 0.88)  
≈ 0.88 × 0.12  
≈ 0.1056  

Answer: σ′(2) ≈ 0.106  

------------------------------------------------------------  
KEY IDEA  

- The derivative of the sigmoid is always σ(x) × (1 − σ(x)).  
- It reaches its maximum at x = 0 (value = 0.25).  
- For large positive or negative x, the derivative gets very small → vanishing gradient problem.  

------------------------------------------------------------  
LOGISTIC REGRESSION EQUATION AND ODDS  

1. Odds  
- Odds = Probability of event happening ÷ Probability of event not happening  
- Formula:  
  p(x) / (1 − p(x)) = e^(z)  
  where z = w·X + b  

2. Log-Odds (Logit)  
- Taking the natural log of the odds gives:  
  log [ p(x) / (1 − p(x)) ] = w·X + b  
- This means the log-odds are modeled as a linear function of the inputs.  

3. Final Logistic Regression Equation  
- Rearranging gives the probability formula:  
  p(x) = e^(w·X + b) / (1 + e^(w·X + b))  
- Equivalent form:  
  p(x) = 1 / (1 + e^(−(w·X + b)))  
- This represents the probability that the input belongs to Class 1.  

------------------------------------------------------------  
LIKELIHOOD FUNCTION  

- Goal: Find weights (w) and bias (b) that maximize the likelihood of the observed data.  
- For each data point i:  
  - If y = 1 → probability = p(xi)  
  - If y = 0 → probability = 1 − p(xi)  
- Likelihood:  
  L(b, w) = ∏ [ p(xi)^yi × (1 − p(xi))^(1 − yi) ]  

------------------------------------------------------------  
LOG-LIKELIHOOD FUNCTION  

- Taking logs makes it easier to compute:  
  log L(b, w) = Σ [ yi log p(xi) + (1 − yi) log (1 − p(xi)) ]  
- This is the function we maximize to estimate parameters.  

------------------------------------------------------------  
GRADIENT OF LOG-LIKELIHOOD  

- To optimize, we compute the gradient:  
  ∂J/∂wj = Σ (yi − p(xi)) × xij  
- This shows how each weight should be updated during training.  

------------------------------------------------------------  
TERMINOLOGIES  

- Independent Variables: Input features (predictors).  
- Dependent Variable: Target (0 or 1).  
- Logistic Function: Maps inputs to probability between 0 and 1.  
- Odds: Ratio of event happening vs not happening.  
- Log-Odds (Logit): Natural log of odds, modeled linearly.  
- Coefficient: Parameters (weights) showing feature influence.  
- Intercept: Constant term (bias).  
- Maximum Likelihood Estimation (MLE): Method to estimate parameters by maximizing likelihood.  

------------------------------------------------------------  
  EVALUATION METRICS FOR LOGISTIC REGRESSION  

1. Accuracy  
- Measures how many predictions are correct overall.  
- Formula: (True Positives + True Negatives) ÷ Total  

2. Precision  
- Focuses on the quality of positive predictions.  
- Formula: True Positives ÷ (True Positives + False Positives)  
- High precision means fewer false alarms.  

3. Recall (Sensitivity)  
- Measures how many actual positives are correctly identified.  
- Formula: True Positives ÷ (True Positives + False Negatives)  
- High recall means fewer missed positives.  

4. F1 Score  
- Combines precision and recall into one number.  
- Formula: 2 × (Precision × Recall) ÷ (Precision + Recall)  
- Useful when you want balance between precision and recall.  

5. AUC-ROC  
- Plots True Positive Rate vs False Positive Rate at different thresholds.  
- AUC (area under curve) shows overall ability to separate classes.  
- Higher AUC = better performance.  

6. AUC-PR  
- Plots Precision vs Recall at different thresholds.  
- Useful when dealing with imbalanced datasets (where positives are rare).

DIFFERENCES BETWEEN LINEAR AND LOGISTIC REGRESSION  

| Aspect              | Linear Regression                                | Logistic Regression                          |
|---------------------|--------------------------------------------------|---------------------------------------------|
| Definition          | Predicts continuous values                       | Predicts categorical values (0/1, Yes/No)   |
| Problem Type        | Regression problems                              | Classification problems                      |
| Output Type         | Continuous numbers (price, age, etc.)            | Probabilities mapped to categories           |
| Curve/Model Fitting | Best fit line                                    | S-shaped curve (sigmoid)                     |
| Estimation Method   | Least squares                                    | Maximum likelihood estimation                |
| Output Example      | Predict house price                              | Predict if house sells (Yes/No)              |

------------------------------------------------------------  
ASSUMPTIONS OF LOGISTIC REGRESSION  

1. Independent Observations  
- Each data point should be independent.  
- Example: One person’s survey response should not influence another’s.  

2. Binary Dependent Variable  
- The target variable is usually binary (0/1, Yes/No).  
- For multiple categories, extensions like multinomial logistic regression or Softmax are used.  

3. Linearity of Log-Odds  
- The independent variables should have a linear relationship with the log-odds of the outcome.  
- This means the effect of predictors is additive in the logit scale.  

4. No Extreme Outliers  
- Very large or unusual values can distort the model’s coefficients.  
- Outliers should be checked and handled before training.  

5. Large Sample Size  
- Logistic regression works best with a sufficiently large dataset.  
- More data → more stable and reliable predictions.  

------------------------------------------------------------  
LOSS FUNCTIONS  
- Used during training.  
- Tell the model “how wrong” its predictions are compared to actual values.  
- The optimizer (like gradient descent) uses the loss to update weights.  
- Examples: Mean Squared Error (MSE), Cross‑Entropy Loss, Hinge Loss.  
- Think of it as the teacher’s correction guiding the model to improve.  

------------------------------------------------------------  
EVALUATION METRICS  
- Used after training (or during validation).  
- Measure how well the model performs on unseen data.  
- Help humans interpret performance in practical terms.  
- Examples: Accuracy, Precision, Recall, F1 Score, AUC.  
- Think of it as the report card showing how good the model is.  

------------------------------------------------------------  
KEY DIFFERENCE  

- Loss function = internal signal for optimization.  
- Evaluation metric = external measure for performance comparison.  

------------------------------------------------------------  
EXAMPLE  

Logistic Regression for spam detection:  
- Loss function: Binary Cross‑Entropy → minimized during training.  
- Evaluation metrics: Accuracy, Precision, Recall → reported after training to judge how well the model detects spam.  

------------------------------------------------------------  
LOG LOSS  

- In linear regression we use squared loss (L2 loss).  
- Logistic regression uses Log Loss instead, because the sigmoid curve is not linear.  
- Log Loss measures how far the predicted probability is from the actual label (0 or 1).  
- Formula (for one example):  
  - If actual y = 1 → loss = −log(p)  
  - If actual y = 0 → loss = −log(1 − p)  
- For the whole dataset, we take the average across all examples.  

------------------------------------------------------------  
WHY LOG LOSS INSTEAD OF SQUARED LOSS  

- Squared loss works well when outputs change at a constant rate (linear models).  
- Logistic regression outputs probabilities on an S‑shaped curve. Near 0 or 1, tiny changes in input cause big changes in probability.  
- Squared loss struggles to capture this precision.  
- Log Loss handles probabilities better because it grows large when the model is very confident but wrong.  

------------------------------------------------------------  
INTERPRETATION  

- Log Loss = 0 → perfect predictions.  
- Lower Log Loss → better model.  
- It penalizes wrong predictions more strongly when the model is confident but incorrect.  

------------------------------------------------------------  
REGULARIZATION  

Regularization is a mechanism for penalizing model complexity during training.  
- Without regularization, logistic regression can keep driving loss toward 0 when there are many features, leading to overfitting.  
- Regularization helps keep weights small and prevents the model from fitting noise.  

Two common strategies:  
1. L2 Regularization  
   - Adds a penalty proportional to the square of the weights.  
   - Encourages smaller, more stable coefficients.  
2. Early Stopping  
   - Stops training before the loss reaches its absolute minimum.  
   - Prevents the model from overfitting by halting while loss is still decreasing.  

------------------------------------------------------------  
KEY IDEA  

- Log Loss = measures prediction uncertainty.  
- Regularization = controls complexity and prevents overfitting.  
- Together, they make logistic regression stable and generalizable.  

------------------------------------------------------------
COST FUNCTION FOR REGRESSION

Regression models commonly minimize Mean Squared Error (MSE), which is the average squared difference between predicted and actual values.

------------------------------------------------------------
R² SCORE

R² (coefficient of determination) measures how much of the variation in the output is explained by the model.  
R² = 1 means perfect prediction.  
R² = 0 means the model predicts no better than the average.

------------------------------------------------------------
RESIDUALS

Residual = actual value – predicted value.  
Residual analysis helps detect:
- non‑linearity  
- outliers  
- heteroscedasticity  
- poor model fit  

------------------------------------------------------------
FEATURE SCALING

Regression models like gradient descent and SVR often require feature scaling (standardization or normalization) to improve performance and convergence.

------------------------------------------------------------
OUTLIERS

Outliers can strongly affect regression because the model minimizes squared error.  
Robust regression methods like Huber or RANSAC can reduce outlier impact.

------------------------------------------------------------
CORRELATION VS CAUSATION

Regression identifies relationships between variables but does not prove causation.

------------------------------------------------------------
TRAIN / VALIDATION / TEST SPLIT

Regression models must be evaluated on validation and test sets to measure real‑world performance and tune hyperparameters.

------------------------------------------------------------
MODEL COMPLEXITY

Model complexity describes how flexible or powerful a model is.  
Dataset size is the amount of data used to train the model.

- A complex model with small data will memorize and overfit instead of learning patterns.  
- A simple model with large data will underfit because it cannot capture all patterns in the rich dataset.

High‑dimensional datasets have many features.  
Low‑dimensional datasets have few features.

------------------------------------------------------------
DATASET SIZE CATEGORIES

Size: Small
Rows (instances): up to ~10k
Columns (features): < 50
Typical Handling: Easy to compute correlations directly (df.corr() is fine).

Size: Medium
Rows (instances): ~10k – 1M
Columns (features): 50 – 500
Typical Handling: Still feasible, but may need sampling or dimensionality reduction.

Size: Large
Rows (instances): ~1M – 100M
Columns (features): 500 – 10k
Typical Handling: Correlation matrix becomes heavy; use distributed computing (Spark, Dask) or approximate methods.

Size: Really Large
Rows (instances): >100M
Columns (features): >10k
Typical Handling: Full correlation matrix is impractical; rely on feature selection, embeddings, or specialized algorithms.
